## Description

Keep the useful websites one double-click away. SaveLink turns any web address into a desktop shortcut that carries the site's own icon, so your Desktop or any folder shows recognisable logos instead of a row of identical browser icons.

Copy a link and start SaveLink: the address is already filled in. SaveLink looks up the page title and finds the site's best icon, using its high-resolution touch icon where there is one. Check the name, click Create Shortcut, and the shortcut is on your Desktop.

Choose how each shortcut opens:
• In your default browser, whichever browser that is when you click it.
• In a specific browser installed on your PC, such as Edge, Chrome, Firefox, Brave, Vivaldi or Opera.
• In its own app window, without tabs or address bar and with its own taskbar button, so a web app such as mail, a calendar or a chat feels like an installed program (Edge, Chrome, Brave and Vivaldi).

Not happy with the icon? Use your own image, generate a clean letter tile, or go back to the website's icon. Any icon can also be saved as a multi-size .ico file for use elsewhere.

SaveLink is small, fast and private. It has no account, no ads and no tracking: it only contacts the website you enter (and Google's public favicon service if the site has no icon of its own). Shortcuts are ordinary Windows files that keep working without SaveLink.

SaveLink is open source under the MIT license.

## Product features

One per line in Partner Center (max 200 characters each).

- Turns any web address into a desktop shortcut with the website's own icon
- Finds the best icon automatically: high-resolution touch icons, declared icons or favicon.ico
- Fills in a copied link when it starts; drag and drop links, text or .url files onto the window
- Open shortcuts in the default browser, a specific installed browser, or a separate app window
- App-window mode for Edge, Chrome, Brave and Vivaldi: no tabs or address bar, its own taskbar button
- Use your own image, generate a letter tile, or reset to the website's icon
- Save any icon as a multi-size .ico file
- Choose where shortcuts and icons are saved
- Built-in help (F1) and full keyboard support
- No account, ads or tracking; open source under the MIT license
